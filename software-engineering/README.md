# Software Engineering Roadmap

All resources are websites, labs, official docs, or courses (free unless marked Paid). Building things comes first. Git, Docker, Kubernetes, Terraform, Linux and security topics reuse the [networking](../networking/README.md), [cybersecurity](../cybersecurity/README.md) and [data engineering](../data-engineering/README.md) roadmaps.

Every resource is essential unless its description starts with "Supplementary".

## Stage 2: Pick a specialty
| Path | For you if you like... |
|---|---|
| [Frontend Engineer](2-specialties/frontend-engineer.md) | Interfaces, HTML/CSS/JavaScript, React, accessibility, user experience |
| [Backend Engineer](2-specialties/backend-engineer.md) | APIs, databases, authentication, system design, reliability |
| [Mobile Engineer](2-specialties/mobile-engineer.md) | Android, iOS and cross-platform apps |
| [DevOps and SRE](2-specialties/devops-and-sre.md) | CI/CD, containers, infrastructure as code, monitoring, incident response |
| [AI Engineer](2-specialties/ai-engineer.md) | LLM apps, RAG, agents, evaluation, shipping AI features |
