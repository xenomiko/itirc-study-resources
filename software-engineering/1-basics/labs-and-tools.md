# Labs and Tools

**Cost warning:** use free tiers, set spending alerts on any cloud or API account, and keep secrets out of Git. Store keys in environment variables, never in committed files.

**Path at a glance:** VS Code and the terminal (beginner) → Learn Git Branching and [GitHub Skills](../../networking/2-specialties/netdevops.md) (beginner) → Docker ([Get started](../../data-engineering/1-basics/fundamentals.md)) → Codespaces for disposable environments → browser DevTools and Postman for debugging APIs.

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [VS Code documentation](https://code.visualstudio.com/docs) | Beginner | Free | Official docs for the editor, including debugging and extensions. | Set up a productive editor with a debugger and linting. |
| [Learn Git Branching](https://learngitbranching.js.org) | Beginner | Free | Interactive visual Git tutorial. | Understand branches, rebases and merges by seeing them. |
| [GitHub Codespaces](https://docs.github.com/en/codespaces) | Beginner | Free monthly quota + paid | Browser-based dev environment. Check the current free allowance. | Run labs without installing anything locally. |
| [Chrome DevTools documentation](https://developer.chrome.com/docs/devtools) | Beginner to Intermediate | Free | Official docs for inspecting, debugging and profiling web pages. | Debug network calls, layout and performance in the browser. |
| [Postman Learning Center](https://learning.postman.com) | Beginner to Intermediate | Free (paid plans exist) | Docs and tutorials for exploring and testing APIs. | Call, inspect and script tests against HTTP APIs. |
| [Exercism](https://exercism.org) | Beginner | Free | Also in [programming basics](programming-basics.md). Its online editor needs no setup. | Practice in a new language with no local install. |
| [Docker Compose docs](https://docs.docker.com/compose/) | Beginner to Intermediate | Free | Supplementary: defines multi-container dev stacks in one file. | Run an app, database and cache together locally. |
