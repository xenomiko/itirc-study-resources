# Programming Basics

**Path at a glance:** CS50x (big picture) → Python with [CS50P](../../networking/2-specialties/netdevops.md) and the [Python tutorial](../../data-engineering/1-basics/fundamentals.md) → Missing Semester (shell, Git, debugging) → Exercism (daily practice) → Refactoring Guru (clean code and patterns) → [algorithms](algorithms-and-data-structures.md) → pick a specialty. Learn Linux with [Linux Journey](../../cybersecurity/1-basics/fundamentals.md) alongside.

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [Harvard CS50x](https://cs50.harvard.edu/x/) | Beginner | Free (certificate may cost) | Harvard's intro to computer science covering C, Python, SQL and web basics, with problem sets. | Solve problems in code and explain how programs, memory and the web work. |
| [freeCodeCamp](https://www.freecodecamp.org) | Beginner | Free | Interactive browser curriculum with projects. | Write small programs and finish guided projects. |
| [MIT Missing Semester](https://missing.csail.mit.edu) | Beginner to Intermediate | Free | Lectures on the shell, editors, Git, debugging and profiling. | Use the terminal, version control and a debugger confidently. |
| [Exercism](https://exercism.org) | Beginner to Intermediate | Free | Exercises in dozens of languages with automated tests and optional mentoring. | Learn a new language by solving test-driven exercises. |
| [Refactoring Guru](https://refactoring.guru) | Intermediate | Free + paid | Illustrated guides to refactoring, code smells and design patterns. The site's books are paid but the web content is free. | Spot code smells and apply common design patterns. |
| [Helsinki MOOC: Java Programming](https://java-programming.mooc.fi) | Beginner to Intermediate | Free | Supplementary: full Java course with exercises. Pick this if you want a statically typed first language. | Write object-oriented Java with tests. |
| [Rustlings](https://github.com/rust-lang/rustlings) | Intermediate | Free | Supplementary: small exercises for learning Rust. | Read compiler errors and write safe Rust. |
| [roadmap.sh](https://roadmap.sh) | Beginner | Free | Supplementary: community roadmaps for deciding what to study next. | Compare career paths and spot gaps in your skills. |
