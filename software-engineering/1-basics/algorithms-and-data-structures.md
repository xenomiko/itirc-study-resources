# Algorithms and Data Structures

**Path at a glance:** Python Tutor and VisuAlgo (see what code does) → NeetCode roadmap (patterns) → LeetCode (volume) → Princeton or MIT 6.006 (depth). Aim for steady daily practice rather than cramming.

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [Python Tutor](https://pythontutor.com) | Beginner | Free | Step-by-step visualizer for code execution, memory and references. | Trace how variables, lists and recursion behave line by line. |
| [VisuAlgo](https://visualgo.net) | Beginner | Free | Animated visualizations of data structures and algorithms. | See how sorting, trees and graph traversals work before coding them. |
| [NeetCode roadmap](https://neetcode.io/roadmap) | Beginner to Intermediate | Free + paid (check which content is free) | Problems grouped by pattern with video explanations. | Recognize patterns such as two pointers, sliding window and DP. |
| [LeetCode](https://leetcode.com) | Intermediate | Free + paid | Large problem set with an in-browser judge. Some problems and features are premium. | Solve medium problems under time pressure and compare solutions. |
| [Princeton Algorithms, Part I](https://www.coursera.org/learn/algorithms-part1) | Intermediate | Free to audit (check current terms) + paid certificate | University course on sorting, searching, graphs and data structures. | Analyze running time and implement core structures from scratch. |
| [MIT 6.006 Introduction to Algorithms](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/) | Intermediate to Advanced | Free | Lectures, notes and problem sets from MIT OpenCourseWare. | Prove correctness and complexity and design algorithms with DP and graphs. |
| [Big-O Cheat Sheet](https://www.bigocheatsheet.com) | Beginner | Free | Supplementary: quick reference of common complexities. | Look up time and space costs while practicing. |
| [Advent of Code](https://adventofcode.com) | Intermediate | Free | Supplementary: yearly December puzzles, with older years always available. | Practice parsing, simulation and algorithms on varied puzzles. |
| [CP-Algorithms](https://cp-algorithms.com) | Advanced | Free | Supplementary: detailed reference for advanced algorithms. | Study techniques beyond typical interview questions. |

## Project
Implement a hash map, a binary heap and a graph with BFS, DFS and Dijkstra from scratch, with unit tests and a short note on the complexity of each operation.
