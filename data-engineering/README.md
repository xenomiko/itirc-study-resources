# Data Engineering Roadmap

All resources are websites, labs, official docs, or courses (free unless marked Paid). Hands-on practice comes first. Python, Git, Terraform and Linux reuse the [networking](../networking/README.md) and [cybersecurity](../cybersecurity/README.md) roadmaps.

Every resource is essential unless its description starts with "Supplementary".

## Stage 2: Pick a specialty
| Path | For you if you like... |
|---|---|
| [Data Engineer](2-specialties/data-engineer.md) | Building ingestion pipelines, orchestration, reliable batch workflows |
| [Analytics Engineer](2-specialties/analytics-engineer.md) | SQL, data modeling, dbt, turning raw data into trusted tables |
| [Streaming and Big Data](2-specialties/streaming-and-big-data.md) | Spark, Kafka, Flink, large-scale and real-time processing |
| [Data Platform Engineer](2-specialties/data-platform-engineer.md) | Cloud warehouses and lakehouses, infrastructure as code, CI/CD |
| [DataOps and Data Quality](2-specialties/dataops-and-data-quality.md) | Testing, lineage, observability, governance |

Books are intentionally left out. See [books-and-paid](books-and-paid.md) if you want them.
