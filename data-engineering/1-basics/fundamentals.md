# Fundamentals

**Path at a glance:** Python (see the [CS50P row](../../networking/2-specialties/netdevops.md)) → Kaggle Learn (Python, pandas) → Git ([GitHub Skills](../../networking/2-specialties/netdevops.md)) → Linux ([Linux Journey](../../cybersecurity/1-basics/fundamentals.md)) → Docker → [SQL and databases](sql-and-databases.md) → first specialty. Pair with the [Data Engineering Zoomcamp](../2-specialties/data-engineer.md) once you know basic Python and SQL.

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [Python official tutorial](https://docs.python.org/3/tutorial/) | Beginner | Free | The language reference tutorial. Use it after CS50P to fill gaps. | Read and write idiomatic Python, including files, modules and exceptions. |
| [Kaggle Learn](https://www.kaggle.com/learn) | Beginner | Free | Short interactive courses in Python, pandas and data cleaning that run in the browser. | Load, clean and reshape tabular data with pandas. |
| [pandas: 10 minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html) | Beginner | Free | Official quick tour of the main DataFrame operations. | Select, filter, group and join data in pandas. |
| [Docker: Get started](https://docs.docker.com/get-started/) | Beginner | Free | Official tutorial on images, containers and volumes. | Run databases and tools in containers and write a simple Dockerfile. |
| [Docker Compose docs](https://docs.docker.com/compose/) | Beginner to Intermediate | Free | Official docs for defining multi-container setups in one file. | Start a local Postgres plus an app with a single command. |
| [Git and the command line refresher](https://git-scm.com/docs/gittutorial) | Beginner | Free | Supplementary: official Git tutorial if GitHub Skills was not enough. | Commit, branch and merge from the terminal. |
