# SQL and Databases

**Path at a glance:** SQLBolt (syntax) → SQLZoo or Mode (practice) → PostgreSQL tutorial and PGExercises (a real database) → window functions and EXPLAIN (intermediate) → CMU database lectures in [theory](theory.md) (advanced).

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [SQLBolt](https://sqlbolt.com) | Beginner | Free | Short interactive lessons that run in the browser. | Write SELECT, JOIN, GROUP BY and basic INSERT/UPDATE queries. |
| [SQLZoo](https://sqlzoo.net) | Beginner | Free | Interactive exercises on real sample tables. | Practice joins and aggregates until they feel natural. |
| [Mode SQL Tutorial](https://mode.com/sql-tutorial) | Beginner to Intermediate | Free | Lessons with a built-in editor, covering joins, subqueries and window functions. | Analyze data with window functions and subqueries. |
| [PostgreSQL official tutorial](https://www.postgresql.org/docs/current/tutorial.html) | Beginner to Intermediate | Free | The official tutorial for a production-grade open-source database. | Create tables, constraints and views and run queries against a real server. |
| [PGExercises](https://pgexercises.com) | Intermediate | Free | Exercises on one realistic schema, grouped by topic. | Solve harder joins, aggregates and recursive queries. |
| [DuckDB documentation](https://duckdb.org/docs/) | Intermediate | Free | Docs for an embedded analytical database that queries CSV and Parquet files directly. | Run analytical SQL on local files with no server setup. |
| [PostgreSQL: Indexes and EXPLAIN docs](https://www.postgresql.org/docs/current/using-explain.html) | Intermediate to Advanced | Free | Official docs on reading query plans, with the indexing chapter alongside. | Read a query plan and fix a slow query with the right index. |
| [DataLemur](https://datalemur.com) | Intermediate | Free + paid | Supplementary: interview-style SQL questions. Many are free. | Prepare for SQL interview questions. |
| [LeetCode SQL](https://leetcode.com/studyplan/top-sql-50/) | Intermediate | Free + paid | Supplementary: a curated set of SQL problems. Some are premium. | Build speed on common query patterns. |
