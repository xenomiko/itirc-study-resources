# Labs and Tools

Networking is learned by building and breaking things.

| Resource | Type | Level | Free/Paid | Notes |
|---|---|---|---|---|
| Cisco Packet Tracer | Simulator | Beginner | Free | Free with a Networking Academy account. Start here. |
| [Wireshark](https://www.wireshark.org) + Chris Greer (YouTube) | Tool + tutorials | Intermediate | Free | Packet analysis is a core skill for networking and security. |
| [GNS3](https://www.gns3.com) / [EVE-NG Community](https://www.eve-ng.net) | Emulator | Advanced | Free | More realistic topologies than Packet Tracer. |
| [Containerlab](https://containerlab.dev) | Lab tool | Advanced | Free | Lightweight, runs well on Linux and Fedora. |
| [TryHackMe](https://tryhackme.com) | Guided labs | Beginner | Free tier | Networking rooms that lead into cybersecurity. |
