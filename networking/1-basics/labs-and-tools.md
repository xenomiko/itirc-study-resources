# Labs and Tools

**Path at a glance:** Packet Tracer (beginner) → Wireshark with sample captures (beginner to intermediate) → Containerlab or GNS3 (intermediate to advanced).

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [Cisco Packet Tracer](https://www.skillsforall.com) | Beginner | Free | Network simulator. Enrolling in the free "Getting Started with Cisco Packet Tracer" course on Skills for All gives access to the download. | Build and test LANs, VLANs and basic routing before touching real gear. |
| [Wireshark Learn](https://www.wireshark.org/resources) | Beginner | Free | The official learning hub: user guide, tutorials and documentation. | Capture traffic, apply filters and read protocol details. |
| [Wireshark Sample Captures](https://wiki.wireshark.org/SampleCaptures) | Beginner to Intermediate | Free | Community-contributed pcap files for many protocols. Open them as a normal user, never as root. | Practice dissecting real protocols without capturing anything yourself. |
| [Chris Greer (YouTube)](https://www.youtube.com/@ChrisGreer) | Intermediate | Free | Practical Wireshark and troubleshooting walkthroughs. | Diagnose slow or broken connections from packet captures. |
| [TryHackMe: Pre Security path and Network Fundamentals](https://tryhackme.com) | Beginner | Free tier + paid | Guided browser labs. Some rooms are premium. | Apply networking basics hands-on in a guided environment. |
| [Containerlab](https://containerlab.dev) | Intermediate | Free | Lab tool that deploys topologies from a YAML file using Docker. Use free images such as FRR or Nokia SR Linux. | Write a topology as code and deploy or destroy a lab in seconds. |
| [GNS3](https://www.gns3.com) | Intermediate to Advanced | Free | Network emulator with active 2.2.x and 3.x release lines. You supply your own vendor device images. | Run realistic multi-device topologies on your own machine. |
