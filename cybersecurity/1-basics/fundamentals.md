# Fundamentals

**Path at a glance:** Skills for All (concepts) → TryHackMe Pre Security (guided labs) → Linux Journey and Bandit (command line, in parallel) → OWASP Top 10 (web risks) → Cyber Security 101 (consolidation) → pick a specialty. Do the [networking fundamentals](../../networking/1-basics/fundamentals.md) first or alongside.

| Resource | Level | Cost | What it is | You will be able to |
|---|---|---|---|---|
| [Cisco Skills for All: Introduction to Cybersecurity](https://www.skillsforall.com) | Beginner | Free | Short self-paced course with a badge, covering threats, defenses and careers. | Explain core security concepts and the main career paths. |
| [TryHackMe: Pre Security](https://tryhackme.com) | Beginner | Free tier + paid | Guided browser path covering networking, web, Linux and Windows basics. Some rooms are premium. | Use a browser-based attack box and apply basics hands-on. |
| [Linux Journey](https://linuxjourney.com) | Beginner | Free | Browser lessons from first commands to services and networking. | Navigate the shell, manage permissions and processes. |
| [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) | Beginner | Free | SSH wargame where each level teaches a command-line skill. | Find, read, decode and transfer files using only the shell. |
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | Beginner | Free | Ranked list of common web application risks. Check which edition is current. | Name and describe the most common web vulnerabilities. |
| [TryHackMe: Cyber Security 101](https://tryhackme.com) | Beginner to Intermediate | Free tier + paid | Path that consolidates offensive and defensive basics. Much of it is premium, so check which rooms are free. | Apply security fundamentals across several domains. |
| [picoCTF](https://picoctf.org) | Beginner | Free | Supplementary: beginner-friendly CTF with a year-round practice area. | Solve entry-level crypto, forensics, web and reversing challenges. |
| [OverTheWire: Natas](https://overthewire.org/wargames/natas/) | Intermediate | Free | Supplementary: server-side web wargame in the same style as Bandit. | Spot basic web flaws by reading responses and source. |
| [OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org) | Intermediate | Free | Supplementary: concise reference on secure patterns for common problems. | Look up the correct defensive pattern for a given vulnerability. |
