# Cybersecurity Roadmap

All resources are websites, labs, official docs, or courses (free unless marked Paid). Labs come first. Network topics reuse the [networking roadmap](../networking/README.md).

Every resource is essential unless its description starts with "Supplementary". Only test systems you own or have written permission to test.
