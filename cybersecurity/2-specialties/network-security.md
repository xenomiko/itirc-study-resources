# Network Security

**Role:** protects networks with firewalls, VPNs, segmentation and monitoring, and detects attacks.
**Prerequisites:** [Fundamentals](../1-basics/fundamentals.md) and [networking fundamentals](../../networking/1-basics/fundamentals.md).

The full resource list lives in the networking roadmap, so it is not repeated here: [Network Security specialty](../../networking/2-specialties/network-security.md).

**Path at a glance:**
1. Beginner: TryHackMe Network Security and Traffic Analysis, then Wireshark docs and [sample captures](../../networking/1-basics/labs-and-tools.md).
2. Intermediate: OPNsense docs, Suricata docs, Malware-Traffic-Analysis.net.
3. Advanced: Zeek docs, then Security Onion docs. Essential for the SOC path, otherwise supplementary.

**Safety:** malware pcaps belong in an isolated VM with no shared folders.
